# 规划

本目录统一存放这个 Agent 项目的所有计划，用于明确每一步的目标、范围和验收标准，避免学习与实现过程中跑偏。以后新增和调整计划都放在这里。

项目有两个目标：通过亲自推导、实验和阅读优秀源码理解 Agent 核心机制；逐步形成别人能使用、自己能讲清设计取舍的求职作品。

## 使用方式

- 按里程碑逐步推进，每个里程碑写清目标、步骤、验收标准和暂不做的内容。
- 每一步先讨论为什么需要、输入输出是什么，再做最小实现并验证；带着具体问题阅读源码或论文。
- 验收通过后勾选对应步骤，再进入下一步。发现问题时调整当前计划，不提前扩展后续架构。
- 后续计划使用清楚的中文名称；新的里程碑按编号递增，并在下方登记。执行以本目录当前计划为准。
