# 里程碑 2 Feature 12 实施计划

按用户确认的技术设计和 60 项验收标准执行。基线 `main` 的 `65b2d27` 已包含 Feature 10，沿用 TypeScript、SQLite 和 React。设计与验收位于 `planning/里程碑2/feature12/`。

- [x] 角色与权限。对照 Pi 的角色文件和作用域，验证旧工作区默认关闭项目角色、同名优先级、请求前更新角色摘要和启动前重新授权。子会话按照发起轮可用工具、角色配置与权限取交集。
- [x] 任务与存储。对照 Pi 单项、并行和串行，以及 Hermes 子会话和逐项持久化。用独立 AgentSession 跑每项，单批并行 4 项，总计 8 项。事务关联输入、运行与原调用。验证顺序、续用历史、并发竞争、子会话隔离及重启。
- [x] 消息与停止。复用 Feature 10 已存的会话队列。显式插话绑定当前轮，报告按运行状态投递。普通停止时已接收且未交付的报告保留到下一次有效启动。收尾时新到的报告按用例 55 排在用户队列之后，并触发继续处理。按运行编号单独停止，按主会话归属执行 `/stop`。验证队列、停机竞争和补送去重。
- [x] 网页与验收。对照 DSH 工具行和现有 SI 任务卡片，按服务端状态同步。用 Chromium 核对显示、刷新、单独停止和 `/stop`。完成受控案例、全仓回归与获授权的实际模型案例 59、60，按案例记录证据。
