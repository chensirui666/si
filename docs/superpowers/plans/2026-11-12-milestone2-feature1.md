# 里程碑 2 Feature 1 实施计划

依据 [技术设计](../../../planning/里程碑2/feature1/feature1-多模型供应商与模型切换技术设计.md) 与 [27 个验收案例](../../../planning/里程碑2/feature1/feature1-多模型供应商与模型切换验收标准.md)。

1. 模型层从 Pi 的本地目录读取提供方、模型与档位。先验证仅本地已配置的路由进入列表，再用受控流验证实际请求、历史转换、用量和中止。
2. 在现有 SQLite 事务里保存默认选择和会话选择。会话在接受消息前核对页面选择，任务接收后固定模型和档位。验证旧库、重试、事务和容量恢复。
3. 接通设置与输入框的模型菜单。沿用 HTTP 回执与 WebSocket 快照，验证跨标签页和过期选择下的草稿恢复。
4. 跑受影响包、完整构建与网页入口测试。逐型号执行真实 API 用例，按实际入口、凭据条件和结果记录证据。
