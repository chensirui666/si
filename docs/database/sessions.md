# `sessions` 会话

一行代表一段已保存的会话。应用在直接创建会话或接收草稿的首次提交时写入这行，之后用它定位会话历史和所属工作区。

## 运行案例

用户在「照片整理」工作区新建一个空白会话。

| 写入时机 | 这张表写入什么 |
| --- | --- |
| 服务端创建会话时 | 新增一行，记录新会话的 `id`、工作区的 `workspaceId`、初始标题 `新会话` 和创建时间 `createdAt`。此时用户还可以没有发送任何消息。 |

## 字段

| 字段 | SQLite 类型 | 可空 | 数据库规则 | 含义与应用规则 |
| --- | --- | --- | --- | --- |
| `id` | `TEXT` | 否 | PK | 会话 ID。恢复会话摘要时要求非空字符串。 |
| `workspaceId` | `TEXT` | 否 | — | 所属工作区 ID。通过工作区登记文件解析为本机目录。恢复会话摘要时要求非空字符串。 |
| `name` | `TEXT` | 否 | — | 会话显示名。初始标题由应用写入，可后续更新。读取时要求非空字符串。 |
| `createdAt` | `TEXT` | 否 | — | 创建时间。写入时使用 ISO 8601 UTC 字符串，如 `2026-11-25T08:30:00.000Z`。读取时要求日期可解析。 |

## 读取规则

- 会话列表按插入顺序读取。
- API 列表中的 `hasScheduledTask` 是查询时计算的标记。若会话有一条启用、未删除、有下次触发时间且复用该会话的计划，列表会返回该标记。
