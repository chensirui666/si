# 视觉设计规范

v0.1 协商稿。配色方向、字体、字号与字重已确认；具体色值、布局和控件尺寸仍为提案。

参考 Wispr Flow 的柔和与留白，参考 Codex、DSH 的工作界面。整体简洁、紧凑、易读；功能范围以 `planning/` 为准。

## 颜色

| 用途 | 色值 | 含义与使用位置 |
| --- | --- | --- |
| 主色、主要文字 | `#1A1A1A` | 主要操作与核心内容：发送按钮、正文、标题、输入文字 |
| 页面背景 | `#FFFFFF` | 工作与阅读空间：页面、消息区、输入框 |
| 反白文字 | `#FFFFFF` | 黑色按钮上的文字和图标 |
| 浅色背景 | `#F7F7F5` | 托起一组内容：用户消息、代码块、次级面板 |
| 交互背景 | `#F0F0EE` | 次级按钮悬停、列表选中；选中另加文字或图标标记 |
| 主按钮悬停 | `#333333` | 鼠标指向主要操作 |
| 次级文字 | `#61666B` | 辅助理解：说明、占位提示、工具说明 |
| 弱化文字 | `#707070` | 补充信息：时间、来源、快捷键；只用于白底或浅色背景 |
| 装饰边框 | `#DEDEDB` | 分组：分割线、非交互容器边框；聊天输入区的弱化边界 |
| 控件边界 | `#8A8A85` | 需要独立描边以辨认操作区域的控件 |
| 成功 | `#167544` | 已保存、工具执行成功 |
| 注意 | `#8A5700` | 达到限制、需要处理的问题 |
| 错误 | `#B42318` | 请求失败、保存失败、危险操作文字 |

- 灰阶负责辅助层次；红黄绿仅表达状态，状态同时配文字或图标。
- 正文保持近黑；链接用近黑加下划线。黑色实心用于当前区域的主要操作。
- 弱化文字不放在交互背景上；文字对比度至少 4.5:1，必要控件边界至少 3:1。

## 字体

| 类型 | 字体 | 使用位置 |
| --- | --- | --- |
| 设计字 | EB Garamond | 产品名、欢迎标题；固定英文，使用 Wispr Flow 同款衬线字体 |
| 正文 | Noto Sans CJK SC | 中英文正文、控件、普通页面标题 |
| 代码（另计） | Noto Sans Mono CJK SC | 代码、命令、需要对齐的技术输出 |

设计字和正文各一款，代码另算。设计字只用于产品名和欢迎标题，两处固定英文，不随界面语言切换翻译。其余界面文案使用正文字体，按界面语言显示；消息与用户输入保持原文。

以上字体均采用 SIL OFL 1.1，可免费商用、嵌入和随应用分发；分发时保留版权和许可文件，不单独出售字体。许可：[设计字](https://github.com/google/fonts/blob/main/ofl/ebgaramond/OFL.txt)、[正文与代码](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)。实现时随应用提供字体文件。

## 字号、字重与文字颜色

尺寸单位为 px。字重统一三档：400 用于阅读和设计字，500 用于操作，600 用于标题和短重点。

| 角色 | 字号 / 行高 | 字重 | 颜色 | 使用位置 |
| --- | --- | --- | --- | --- |
| 产品名 | 24 / 32 | 400 | 主要文字 | 品牌识别；固定英文，使用设计字 |
| 欢迎标题 | 32 / 40 | 400 | 主要文字 | 独立欢迎文案；固定英文，使用设计字 |
| 页面标题 | 20 / 28 | 600 | 主要文字 | 页面、主要区域 |
| 分组标题 | 16 / 24 | 600 | 主要文字 | 设置分组、回复中的次级标题 |
| 正文 | 14 / 24 | 400 | 主要文字 | 用户消息、AI 回复、输入草稿 |
| 操作与标签 | 14 / 20 | 500 | 主要文字／反白 | 按钮、菜单、字段名、工具名 |
| 说明与过程 | 13 / 20 | 400 | 次级文字 | 辅助说明、运行过程；错误改用状态色 |
| 补充信息 | 12 / 18 | 400 | 弱化文字 | 时间、来源、快捷键 |
| 代码 | 14 / 24 | 400 | 主要文字 | 代码块、命令、技术输出 |

用户消息、AI 回复与输入正文保持同一字号。字距统一为 0，不整段加粗；关键说明不用 12px 小字。

## 间距

越相关的内容越近，越独立的内容越远，主要使用 4px 的倍数。

| 间距 | 含义 | 使用位置 |
| --- | --- | --- |
| 4px | 几乎是同一件事 | 标签与小标记 |
| 8px | 同一操作、紧密一组 | 图标与文字、相邻小控件、标签与控件 |
| 12px | 组件内分组 | 输入内容与工具条、连续过程项 |
| 16px | 标准内容留白 | 容器内边距、代码块内边距、正文段落 |
| 24px | 不同内容块 | 不同消息、内容与操作区 |
| 32px | 不同分组 | 设置分组、独立内容区域 |
| 48px | 独立品牌展示 | 欢迎标题与工作区域 |

段落间距只用于结构化正文，不改变用户原文的空格、缩进与空行。

## 布局与控件

| 对象 | 统一规则 |
| --- | --- |
| 内容区 | 最大宽度 760px；消息与输入框同轴居中；两侧留白 24px，小屏至少 16px |
| 按钮 | 高 36px，左右内边距 12px，图文间距 8px，圆角 8px；次要操作用文字、浅底或描边 |
| 图标按钮 | 36 × 36px；触屏操作目标至少 44 × 44px |
| 图标 | 线性风格，默认 16px、描边 1.5px |
| 输入框 | 白底，内边距 16px，圆角 16px，恒定 1px 弱化边界；常态与聚焦使用相同轻微阴影，高度随内容变化；占位提示用次级文字，输入位置由光标标示 |
| 聚焦 | 输入区、消息滚动区和按钮聚焦时不改变边框、不增加外轮廓或光圈；按钮与消息区需要焦点提示时使用高对比的小点，不改变布局，消息区标记不随内容滚动 |
| 按钮反馈 | 浅色按钮悬停用 `#F0F0EE`、按下用 `#DEDEDB`；黑色发送按钮悬停用 `#333333`、按下恢复 `#1A1A1A` |
| 消息滚动区 | 白底无框；保留 Tab 导航、键盘滚动及局部焦点提示 |
| 禁用 | 浅底和弱化文字，同时禁止操作；不显示悬停或按下反馈 |
| 用户消息 | 浅色背景，内边距 16px，圆角 16px；保留原文 |
| AI 回复 | 直接在白底排版，正文不额外套卡片或阴影 |
| 代码块 | 浅色背景，内边距 16px，圆角 12px；长行在容器内横向滚动 |
| 标签 | 短标签可用胶囊圆角 9999px |
| 边框与浮层 | 边框统一 1px；输入框例外使用固定阴影 `0 2px 12px 0 rgba(0, 0, 0, 0.04)`；浮层使用阴影 `0 8px 24px 0 rgba(0, 0, 0, 0.08)` |

视觉调整不改变已确认的“发送后保持阅读位置”行为，也不提前增加功能。

Feature1 标题只保留“聊天”，不展示“本地”标识；输入区不常驻显示快捷键提示。Enter 发送、Shift+Enter 换行的行为保持不变。

焦点提示由组件统一负责，避免默认光圈与页面样式重复叠加。`:focus-visible` 由浏览器判断是否需要提示，不能视为仅键盘操作才触发；高对比度模式下局部标记仍应可见。悬停是短暂反馈，选中状态需另外持续标明。
