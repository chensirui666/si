# 维护项目说明

1. 从当前工作区确定最近的 Git 仓库根。用 ls 检查当前目录及各级父目录的 .git（目录或 worktree 指针文件），无 Git 仓库时用当前工作区。
2. 用 read 查看目标根的 AGENTS.md、开发文档及实际命令定义。检查用户要求变更的命令和现有约定，保留其他内容。
3. 用 edit 精确修改已有 AGENTS.md。需要新建时用 write。只记录能由该仓库核对的内容。
4. 用 read 核对实际保存的内容，回复时说明路径和证据。
